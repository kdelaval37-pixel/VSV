Les captures mobiles sont de l’émulation Chromium et ne prouvent pas un test sur iPhone/Android réel. Les modèles PDF et `src/style.css` sont identiques au commit précédent ; le nouveau style est dans `ui-polish.css`, limité à l’écran.
